# Digital-Banking-Fraud-Risk-Analytics

# Project Overview 
This project demonstrates an end-to-end banking fraud analytics solution using MySQL and Power BI.
The project simulates digital banking transactions and provides interactive dashboards to monitor fraud trends, customer risk, merchant performance, and transaction analytics.


# Business Problem
Banks process millions of digital transactions every day. Detecting suspicious activities and monitoring fraud trends are critical for reducing financial losses and improving customer security.

This dashboard helps business users identify:

- Fraud trends over time
- High-risk customers
- High-risk merchants
- Fraud-prone payment channels
- Transaction distribution across locations
